# 时间区块记录器（完整版 v2.2）

跨平台时间区块记录应用：一套 Flutter 代码，可编译为 Android APK 与 Windows 桌面程序。数据全部保存在本机，无网络、无账号、无广告、无锁机、无应用强制拦截。
自用，纯ai写的，如有建议可提出。

## 功能

### 分类与事件
- 五个固定顶层分类（不可新增、删除、修改）：工作学习、自由恢复、娱乐、睡觉、其他事件。
- 事件管理：新建、修改、删除、收藏事件，每个事件归属一个分类；内置 11 个初始事件；收藏事件在选择列表置顶展示。
- 每个事件支持备注：可在开始计时前、计时中（计时页“编辑备注”）或计时结束后的记录编辑框里增改。

### 日期模式
- 每天三种模式：工作日、休息日、其他；默认周规则：周一至周五工作日，周六周日休息日。
- 支持手动修改任意一天的模式（首页），也可恢复默认。
- 工作日、休息日各有独立的每日目标时长（按分类，可编辑，设置页可折叠节省空间）；其他模式不做目标对比、不设目标，仅记录时间。
- 每日目标合计自动钳制在 24 小时内、每周目标合计自动钳制在 168 小时内，输入超额时给出提示。
- 每天支持简短备注与每日复盘文本（首页编辑、统计页查看）。

### 计时器
- 从事件列表选择事件开始计时，支持正计时与倒计时（可设置预估时长，倒计时结束本地通知提醒）。
- 开始 / 暂停 / 继续 / 结束；结束弹出二次确认防误触，自动保存记录（含实际时长、暂停累计）。
- 计时状态持久化：正在运行 / 暂停中的计时写入本地数据库，应用被杀后台后重新打开会按当前时间补算逝去时长并恢复计时；手动结束后自动清空运行状态。
- 支持手动补录历史时间段记录。
- 每条记录支持添加多个自定义标签；统计页可按标签筛选。

### 统计
- 日视图：顶部日期选择器（上一天 / 下一天 / 日历跳转任意日期，支持未来日期），默认选中今天。
- 24 小时纵向时间轴：顶部缩略总览 + 下方可滚动详细轴；真实计时块与空白「其他」块完整铺满 0-24 小时；点击色块修改分类或生成真实计时记录，长按可跨日期对比同一时刻；支持跨零点计时渲染。
- 分类占比饼图（随屏幕缩放）+ 五类总时长与每个事件耗时；备注、复盘完整展示（不截断），点击弹出独立编辑弹窗；复盘弹窗顶部附带当日时间简易分析提示（工作日/休息日话术，其他模式与无记录时隐藏）。
- 周视图：统计今天（含）向前 7 天，只渲染有事件记录的有效日期卡片；日均时长 = 总时长 / 有效记录天数；一周无记录时展示「本周暂无记录」；另展示分类占比饼图与周目标完成进度。
- 记录页：全部记录列表，标签筛选，点击可编辑已完成计时（改事件/起止时间/标签/备注）或删除。

### 身体与娱乐提醒
- 起身活动提醒：工作学习类计时运行时，连续 50 分钟触发本地通知（其他模式下同样生效）。
- 休息喝水提醒：可开关，默认 60 分钟间隔，30–120 分钟可自定义，所有日期模式均生效。
- 每日睡觉提醒：设置页可开关并自定义时间（默认 23:00），到点推送「该睡觉了，请完成今日复盘」，点击通知直接打开当日复盘编辑弹窗（附带当日时间分析提示）；Android 使用本地定时通知，重启自动恢复。
- 工作时段娱乐提醒：设置页维护娱乐应用/软件列表并拥有总开关；工作学习计时运行且非其他模式时，Android 检测前台 App（需“使用情况访问”权限）、Windows 检测前台窗口标题；命中列表弹出提醒“当前处于工作学习计时，请勿使用娱乐应用”。只提醒，不强制关闭、不锁机；iOS 不提供该监控模块。

### 数据
- JSON 导出 / 导入合并（新时间戳覆盖旧记录）；CSV 导出备份；全部本地存储，手机与电脑之间手动拷贝 JSON 文件同步。
- 主题：浅色 / 深色 / 跟随系统。

## 目录结构

```text
lib/
  main.dart                  # 入口：初始化通知并加载本地数据
  app.dart                   # MaterialApp、主题（浅/深/系统）
  models/                    # 分类/事件/记录/每日模式/每日附加信息/设置/计时快照/聚合数据
  state/app_state.dart       # 全局状态：事件、计时器（含杀后台恢复）、统计、提醒调度、导入导出
  services/                  # 本地存储、JSON/CSV、本地通知、提醒引擎、娱乐监控
  pages/                     # 首页/计时/统计/设置/事件管理
  widgets/                   # 分类进度条、分类饼图、24小时时间轴、备注/复盘编辑弹窗
android/                     # Android 原生：通知权限、使用情况访问通道
windows/                     # Windows 原生：前台窗口标题通道
test/                        # 数据模型、合并、迁移单元测试
```

## 构建

环境要求：Flutter 3.38+（使用 Flutter 3.47.2 / Dart 3.13 验证）。

```bash
# 1. 获取依赖
flutter pub get

# 2. Android APK
flutter build apk --release
# 产物：build/app/outputs/flutter-apk/app-release.apk
# 首次安装后需在系统设置中授予“使用情况访问”权限（用于娱乐提醒）

# 3. Windows 桌面程序（需要 Visual Studio 2022 + C++ 桌面开发组件，
#    并开启系统“开发者模式”以支持插件符号链接）
flutter build windows
# 产物：build/windows/x64/runner/Release/time_block_recorder.exe

# 4. 运行单元测试
flutter test
```

## 数据同步（手动）

1. 在 A 设备「设置 → 导出 JSON 备份」，把文件拷贝到 B 设备。
2. 在 B 设备「设置 → 导入 JSON 合并」：事件按 id 覆盖，计时记录按时间戳去重（新覆盖旧），每日备注/复盘按日期合并，目标与设置以导入文件为准。
3. CSV 备份用于外部查看/归档，不参与合并。
